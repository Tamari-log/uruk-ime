# リポジトリ名・プロダクト名の候補

GitHub 上のリポジトリ名（URL のスラッグ）は **英小文字・数字・ハイフン**が無難です。  
以下から 1 つ選び、GitHub の **Settings → General → Repository name** などでリネームできます（ローカルフォルダ名は任意）。

| # | リポジトリ名（例） | 一言 |
|---|-------------------|------|
| A | `CuneiformInput` | 現状のフォルダ名と一致。機能が直伝わる。 |
| B | `cuneiform-ime` | 「IME」と分かりやすい。一般的な命名。 |
| C | `wedgeboard` | wedge（楔形）＋ keyboard の造語。短い。 |
| D | `meso-keys` | Mesopotamia を連想。覚えやすい英語。 |
| E | `sumero-board` | シュメール語入力・学習寄りの印象。 |
| F | `claytablet-keyboard` | 粘土板のメタファー。ユニークだがやや長い。 |
| G | `uruk-ime` | 古代都市ウルク。短く記号っぽい。 |

**アプリ表示名**（端末上）は現状 `楔形文字入力` のままで問題ありません。  
リポジトリ名を変えても `applicationId`（`com.cuneiform.input`）はそのままでよい典型例です。

選択したら、ルートの `README.md` のタイトル横の英語副題を、必要なら候補に合わせて調整してください。
